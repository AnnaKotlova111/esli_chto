# Справочник домов: г. Вичуга (Ивановская область)

Исходные данные для приложения. Из них скрипт `scripts/import-houses.mjs` собирает `packages/core/src/data/city.json`:

```bash
npm run data:import
```

## Файлы

| Файл | Содержимое |
|---|---|
| `houses.csv` | Адрес дома (`улица, номер, населённый пункт`) → название управляющей организации. 224 строки, 223 уникальных адреса: 218 в г. Вичуге и 5 в пос. Каменка (Вичугский район). |
| `organizations.csv` | Карточки организаций: название, тип (УК, ТСЖ, ЖСК, ТСН), адрес, телефон диспетчерской, телефоны, число домов по карточке, ИНН, ОГРН, e-mail, сайт. «–» – данных нет. |
| `services.csv` | Городские службы: код стороны (`water_utility`, `heat_utility`…), название, телефоны в виде `подпись:номер; подпись:номер`, часы работы, адрес, e-mail, сайт, пояснение. Одинаковы для всех домов. |
| `meta.json` | Город, регион, населённые пункты, префикс идентификаторов домов, дата и источник. |

## Источник

- Карточки управляющих компаний – mingkh.ru.

- Контакты городских служб – сайты организаций и администрации г.о. Вичуга, собраны вручную.

## Что проверяет импорт

- Каждый дом ссылается на существующую карточку организации, тип организации известен.
- Адрес разбирается на улицу, номер и населённый пункт; идентификатор дома подходит для параметра запуска мини-приложения (`[A-Za-z0-9_]`).
- Идентификаторы домов не совпадают.
- Телефоны городских служб – в едином формате `+7 (код) номер` или `8 (800) …`, ровно 11 цифр; служба без телефона попадает в предупреждения.
- Расхождения не исправляются молча, а печатаются как предупреждения и сохраняются в `city.json` (`warnings`).

## Чего в данных нет

- Этажности, наличия лифта, газа, мусоропровода, подвала. Поэтому в приложении по умолчанию показываются все объекты, а житель может отметить, чего в его доме нет.
- Телефонов отдельных лифтовой и домофонной организаций: заявки по лифту принимает диспетчерская управляющей организации дома, телефон домофонной компании указан на панели домофона или в квитанции.

## Как обновить

1. Заменить строки в CSV (кодировка UTF-8, разделитель – запятая, поля с запятыми – в кавычках).
2. Обновить дату в `meta.json`.
3. `npm run data:import` – прочитать предупреждения.
4. `npm test` – тесты проверяют, что у каждого дома есть организация с телефоном в правильном формате.
