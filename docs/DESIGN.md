# Дизайн-система «Calm Civic UI»

Главная идея: человек не знает, что делать, а приложение спокойно показывает следующий шаг. Каждый экран строится по схеме «проблема → ответственность → действие».

## Токены

Все цвета, радиусы и размеры заданы переменными в `apps/webapp/src/ui/tokens.css`, в компонентах цвета не прописываются вручную.

| Токен | Светлая тема | Назначение |
|---|---|---|
| `--color-primary` | `#2563EB` | Действие: кнопки, выбранные объекты, активная навигация, маркеры |
| `--color-primary-dark` | `#173B6C` | Заголовки, важный текст |
| `--color-primary-soft` | `#DCEEFF` | Информационные блоки, фон выбранных зон, вторичные кнопки |
| `--color-background` | `#F6F8FA` | Фон интерфейса |
| `--color-surface` | `#FFFFFF` | Карточки и поверхности |
| `--color-text` / `--color-text-secondary` | `#172033` / `#667085` | Основной и вторичный текст |
| `--color-critical` | `#D92D20` | Только реальная опасность: «Опасно», «Позвонить 112» |
| `--color-warning` | `#E98A15` | Срочность и предупреждения («Срочно», «Спорный случай») |
| `--color-success` | `#1F8A5B` | Подтверждённый результат («Ответ однозначный») |
| `--radius-card` / `--radius-control` / `--radius-small` | 16 / 12 / 8 px | Большие карточки / поля и кнопки / служебные элементы |
| `--button-height` | 52 px | Высота всех основных кнопок |
| `--icon-size` | 24 px | Базовый размер иконок |

Если на телефоне включена тёмная тема, приложение берёт те же токены с оттенками для тёмного фона. Мелкий текст на жёлтом фоне использует более тёмный оттенок (`--color-warning-text`), чтобы оставаться читаемым.

Компоненты официального UI-кита MAX (кнопки, поля ввода, текстовое поле, индикатор загрузки) получают шрифт, цвета и радиусы через свои переменные, которые направлены на эти токены. Поэтому они выглядят частью той же системы.

## Единые компоненты

| Компонент | Файл | Что делает |
|---|---|---|
| `Button` | `ui/Button.tsx` | Все действия: primary, critical, secondary, ghost; высота 52 px; может быть ссылкой `tel:` |
| `ServiceCard` | `ui/ServiceCard.tsx` | Карточка организации: иконка и название, тип, зона ответственности, режим работы, «Позвонить», «Почему сюда?» |
| `SceneMarker` | `ui/SceneMarker.tsx` | Интерактивная подпись на иллюстрации со всеми состояниями |
| `BottomSheet` | `ui/BottomSheet.tsx` | Одна шторка для карточек объектов, ответа, обращения и служебных экранов |
| Иконки | `ui/icons.tsx` | Все иконки приложения в одном файле |
| Метки, блоки, списки | `ui/parts.tsx` | `Callout`, `Badge`, `Section`, `Segmented`, `ListRow`, `Chip` |

## Состояния объектов на схеме

| Состояние | Как выглядит |
|---|---|
| По умолчанию | Нейтральная иллюстрация, подпись с синим значком нарисована на картинке |
| Наведение или фокус | Синяя обводка плашки подписи |
| Выбран | Обводка с ореолом и маркер 40 px с иконкой объекта на месте значка |
| Недоступен | Плашка приглушена, рядом метка «нет в доме», нажатие отключено |
| Переход на другую схему | Синяя стрелка у подписи «Подъезд» |

Зоны нажатия рассчитаны по пикселям иллюстраций (`tools/detect-hotspots.mjs`). Они чуть шире плашек, чтобы по ним было удобно попадать пальцем, и не накладываются друг на друга.

## Экстренный режим

Система та же, меняется вес: красная рамка, слово «Опасно», значок и одна главная кнопка «Позвонить 112» (или 104) над всем остальным. Красный цвет используется только при реальной угрозе. Для срочных аварий, например прорыва трубы или отключения света, используется оранжевый блок «Срочно» и обычная синяя кнопка звонка.

## Доступность

- Смысл не передаётся только цветом: у каждого статуса есть слово и значок («Опасно», «Срочно», «Спорный случай», «нет в доме»).
- Основной текст 16 px, кнопки высотой 48-52 px, область нажатия не меньше 44 px.
- Все зоны схемы доступны с клавиатуры (Tab, Enter, пробел) и имеют понятные названия для программ экранного доступа. Схемы переключаются стрелками.
- Фокус хорошо заметен (синее кольцо). Шторка переносит фокус внутрь себя и закрывается клавишей Esc.
- Кому удобнее читать, чем искать на картинке, может открыть под схемой полный список объектов по зонам с фильтром по категориям.
- Если в настройках телефона включено уменьшение движения (iPhone: «Универсальный доступ → Движение», Android: «Удалить анимацию»), шторки и переходы открываются без анимации.
