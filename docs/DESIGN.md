# Дизайн-система «Calm Civic UI»

Ключевое ощущение: «я не знаю, что делать → приложение спокойно показывает, что делать дальше». Формула экрана: **проблема → ответственность → действие**.

## Токены

Все цвета, радиусы и размеры заданы переменными в `apps/webapp/src/ui/tokens.css`; в компонентах цвета не хардкодятся.

| Токен | Светлая тема | Назначение |
|---|---|---|
| `--color-primary` | `#2563EB` | Действие: кнопки, выбранные объекты, активная навигация, маркеры |
| `--color-primary-dark` | `#173B6C` | Заголовки, важный текст |
| `--color-primary-soft` | `#DCEEFF` | Информационные блоки, фон выбранных зон, вторичные кнопки |
| `--color-background` | `#F6F8FA` | Фон интерфейса |
| `--color-surface` | `#FFFFFF` | Карточки и поверхности |
| `--color-text` / `--color-text-secondary` | `#172033` / `#667085` | Основной и вторичный текст |
| `--color-critical` | `#D92D20` | Только реальная опасность: «Опасно», «Позвонить 112» |
| `--color-warning` | `#E98A15` | Срочность и предупреждения («Срочно», «Спорный случай») |
| `--color-success` | `#1F8A5B` | Подтверждённый результат («Ответ однозначный») |
| `--radius-card` / `--radius-control` / `--radius-small` | 16 / 12 / 8 px | Большие карточки / поля и кнопки / служебные элементы |
| `--button-height` | 52 px | Высота всех основных кнопок |
| `--icon-size` | 24 px | Базовый размер иконок |

Тёмная тема – те же токены с оттенками для тёмного фона, включается по настройке устройства. Мелкий текст на жёлтом фоне использует более тёмный оттенок (`--color-warning-text`), чтобы сохранить контраст.

Официальный UI-кит MAX (кнопки, поля ввода, текстовое поле, индикатор загрузки) получает шрифт, цвета и радиусы через свои переменные, направленные на эти токены, поэтому компоненты кита выглядят частью системы.

| Компонент | Файл | Что делает |

| `Button` | `ui/Button.tsx` | Все действия: primary, critical, secondary, ghost; 52 px; может быть ссылкой `tel:` |

## Состояния объектов на схеме

| Состояние | Решение |
|---|---|
| По умолчанию | Нейтральная иллюстрация, подпись с синим значком нарисована на картинке |
| Наведение / фокус | Синяя обводка плашки подписи |
| Выбран | Обводка с ореолом и маркер 40 px с иконкой объекта на месте значка |
| Недоступен | Плашка приглушена, рядом метка «нет в доме», нажатие отключено |
| Переход на другую схему | Синяя стрелка у подписи «Подъезд» |

Зоны нажатия вычислены по пикселям иллюстраций (`tools/detect-hotspots.mjs`) и немного шире плашек – под палец, без наложения друг на друга.

## Экстренный режим

Та же система, но другой вес: красная рамка, слово «Опасно», иконка знака и одна главная кнопка «Позвонить 112» (или 104) – выше всего остального. Красный используется только там, где есть реальная угроза. Срочные аварии (прорыв, нет света) – оранжевый блок «Срочно» и обычная синяя кнопка звонка.

## Доступность

- Смысл не передаётся только цветом: каждый статус – это слово и иконка («Опасно», «Срочно», «Спорный случай», «нет в доме»).
- Основной текст 16 px, кнопки 48–52 px, цели нажатия не меньше 44 px.
- Все зоны схемы доступны с клавиатуры (Tab, Enter, пробел) и имеют понятные названия для программ чтения с экрана; переключатель схем управляется стрелками.
- Фокус заметен (синее кольцо), шторка переносит фокус внутрь и закрывается клавишей Esc.
- Для тех, кому проще читать, чем искать на картинке, под схемой есть полный список объектов по зонам с фильтром категорий.
- Уважается настройка «уменьшить движение».

## Проверка перед сдачей

- [x] Основной сценарий проходится от начала до результата: «выбираю проблему → понимаю, кто отвечает → звоню».
- [x] За несколько секунд понятно, где «Наш дом», а где «Моя квартира»: две вкладки внизу, у каждой своя иллюстрация.
- [x] Интерактивные объекты отличаются от декоративных: подписи с синим значком, при наведении – обводка.
- [x] Красный – только при реальной опасности.
- [x] Ни один важный смысл не передаётся только цветом.
- [x] Русский текст отображается корректно (Inter с кириллицей).
- [x] Нет тупиков: у каждой шторки есть «Назад» и «Закрыть», пустой поиск подсказывает, что делать.
- [x] Источник и дата данных видны на главном экране, в «О приложении» и в ответах бота.
- [x] Критичная информация (экстренные номера, нормы) имеет источник и дату сверки.
