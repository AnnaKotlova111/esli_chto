# Масштабирование и пилот

## Ядро и переменная часть

| Ядро – одинаково для всей России | Переменная часть – своя для города и дома |
|---|---|
| Правила ответственности: 58 объектов, 128 ситуаций, вопросы и выводы | Справочник домов: адрес → управляющая организация |
| Справочник федеральных норм (ЖК, ГК, ПП № 491, 354, 290, 410, 958, 293, 1479, 131-ФЗ) | Контакты организаций: телефоны, диспетчерская, e-mail, ИНН |
| Схемы-иллюстрации и интерфейс | Контакты городских служб: водоканал, теплосеть, ТКО, администрация, ГЖИ |
| Экстренные номера 112, 104, 102 | Региональные нормы: законы о тишине, правила благоустройства |
| Бот, шаблоны обращений, поиск | Особенности конкретного дома: лифт, газ, мусоропровод |

Ядро не меняется при переходе в другой город. Переменная часть подключается данными, без изменения кода.

## Как подключить другой город

1. Создать папку `data/<город>/` с четырьмя файлами – по образцу `data/vichuga/`:
   - `houses.csv` – `address,organization`, адрес в виде «улица, номер, населённый пункт»;
   - `organizations.csv` – карточки организаций (тип УК / ТСЖ / ЖСК / ТСН, телефоны, диспетчерская, ИНН, e-mail, сайт);
   - `services.csv` – городские службы: водоканал, теплосеть, энергосбыт, газ, оператор ТКО, администрация, ГЖИ;
   - `meta.json` – город, регион, населённые пункты, префикс идентификаторов, дата и источник, а также `"demo"`: `true`, если реальных данных пока нет и справочник заполнен тестовыми. Тогда мини-приложение и бот сами показывают пометку «Демо-данные: организации и телефоны вымышлены» – как требует п. 10 ограничений ТЗ.
2. `node scripts/import-houses.mjs data/<город>` – скрипт проверит данные и напечатает расхождения (дубли адресов, организации без домов, расхождение числа домов).
3. `npm test` – тесты проверят, что у каждого дома есть организация с телефоном, идентификаторы годятся для диплинков, а все ответы строятся без ошибок.
4. `npm run docs` и сборка – справочник попадает в мини-приложение и в бота одним бандлом.

Источник данных для любого города – те же открытые реестры: ГИС ЖКХ (раздел «Реестр объектов жилищного фонда»), карточки управляющих организаций, региональная жилищная инспекция. Запуск второго города – это работа с таблицей, а не разработка.

## Риски и допущения

- **Данные устаревают.** Организации меняют телефоны и договоры управления. Меры: дата сведений на экране, совет сверяться с квитанцией, ежемесячное обновление таблиц, в перспективе – кабинет УК.
- **Источник противоречив.** Дом может числиться за двумя организациями. Меры: импорт не исправляет молча, приложение показывает обе.
- **Правила – не консультация юриста.** Меры: спорные случаи помечены, у каждого вывода – норма, шаблон письменного обращения.
- **Нагрузка.** Мини-приложение – статика, бот – один процесс Node.js; для города масштаба Вичуги достаточно минимального сервера, дальше – горизонтальное масштабирование с общим хранилищем выбора дома.
