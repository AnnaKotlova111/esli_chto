# Политика обработки данных

Действует для мини-приложения и чат-бота «Если что» (далее «Приложение»). Оператор: команда проекта «Если что», участники хакатона MAX, трек «Умный город». Связаться с оператором можно в чате с ботом @t527_hakaton_max_bot.

## Какие данные обрабатываются

- ФИО, подъезд, квартира и телефон, которые вы вводите в конструкторе обращения, хранятся только на вашем устройстве: в хранилище MAX, а в обычном браузере в хранилище браузера. На сервер они не передаются. Они нужны, чтобы подставить их в текст обращения, и хранятся, пока вы их не удалите.
- Номер телефона из профиля MAX запрашивается по кнопке «Подставить номер из MAX» и только после вашего разрешения в окне MAX. Номер попадает в поле формы на устройстве и больше никуда не передаётся.
- Выбранный дом, отметки о том, что в нём есть (лифт, газ и т. п.), недавно открытые ситуации и история поиска хранятся только на устройстве, чтобы Приложение помнило ваш выбор.
- Бот получает от MAX ваш идентификатор пользователя и текст сообщения, чтобы ответить. В памяти бота хранятся только выбранный дом, отметка «жду адрес» после команды /house и счётчик запросов для защиты от спама. Они удаляются при перезапуске бота или по команде /forget. Тексты сообщений, в том числе адреса, не сохраняются и не записываются в журналы.
- Приложение не собирает геолокацию, контакты, файлы и платёжные данные, не использует аналитику и рекламные метки и не передаёт данные третьим лицам.

## Кто ещё участвует в обработке

- Переписку с ботом и работу мини-приложения обеспечивает платформа MAX по своим правилам.
- Файлы мини-приложения загружаются с хостинга (сейчас GitHub Pages). Как любой сайт, хостинг видит в технических журналах IP-адрес и сведения о браузере. Приложению эти сведения не передаются.

## Основания и цели

- Вы вводите данные добровольно, чтобы подготовить обращение и получить ответ бота. Для других целей они не используются.

## Как удалить данные

- В мини-приложении откройте «О приложении» и нажмите «Стереть мои данные». С этого устройства удалятся ФИО, подъезд, квартира, телефон, выбранный дом и история.
- В боте команда /forget удаляет выбранный дом.
- Форму можно не заполнять, тогда в тексте обращения останутся поля в квадратных скобках.
- Вопросы об обработке данных и требование прекратить её направляйте в чат с ботом.

## Защита

- Данные пользователя не покидают устройство, поэтому у Приложения нет базы с персональными данными, которую можно похитить.
- Токен бота хранится только в настройках сервера и не попадает в репозиторий. Соединение с API MAX и с Приложением защищено HTTPS.
